Steam Achievement Manager — Python port
========================================

This project is a Python 3 port of gibbed's Steam Achievement Manager
(https://github.com/gibbed/SteamAchievementManager), originally written in C#
using Windows Forms. The Python port re-implements the same functionality on
top of ctypes (for the Steam client DLL) and PySide6 (for the GUI).
